# Branding reference snapshots

These small WebP files preserve the approved visual direction from the original Lumenfall design chat before the project was split into focused workstreams.

- `reference-app-icon.webp` — approved ornate crystal / gold-rift app-icon direction.
- `reference-wordmark.webp` — approved horizontal Lumenfall wordmark direction.
- `reference-ui.webp` — approved polished mobile UI direction showing the new brand language.

These files are references only. The production source of truth is `branding/lumenfall-mark.svg`, which is used by the in-game UI and Android build pipeline.
