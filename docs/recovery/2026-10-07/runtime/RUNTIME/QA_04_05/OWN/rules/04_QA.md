# 04 — Debug / QA

Ejer uafhængig regression, state invariants, runtime, accessibility, performance
og reproduktion. Læs fælles regler, kort status og din præcise reviewopgave.
Læs alle relevante originalkrav og hele den relevante diff; gamle accepts er
ikke automatisk evidens for en ændret kandidat.

Kontrollér faktisk adfærd, failure paths, chronology og negative controls.
Bevar eksisterende gates og forklar enhver oracleændring. Skeln worker-rapport,
egen reproduktion, CI, browser, emulator og fysisk Android.

QA starter read-only og afleverer fund med reproduktion, præcis head/tree og
accept/blockers/ukendte forhold. Fix kræver særskilt writer. Ingen brede audits,
merge, build eller retryloop som følge af et scoped reviewmandat.
