# Testing and debugging guidance

Optional reference for reproduction, regression, runtime, state invariants,
accessibility and performance. Testing and necessary fixes belong to the feature
owner. An explicitly requested read-only review remains read-only; self-review
must not be presented as independent review.

Read original requirements and the relevant complete diff. Record reproducible
baseline failures and cover changed behavior, failure paths, chronology and
negative controls. Preserve existing gates; never weaken an assertion simply
to pass. Fix introduced regressions before completing the task.

Record commands, exact versions, outcomes, blockers and limitations. Distinguish
reported results, local reproduction, CI, browser, emulator and physical device
evidence. Reassess affected checks when the candidate changes. Do not turn a
focused task into a broad audit or an unbounded retry loop.
